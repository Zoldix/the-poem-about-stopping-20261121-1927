A short poem about agency: the power to stop and to stay. Entry for the
[make.fun](https://make.fun/bounty/the-poem-about-stopping-20261121-1927)
competition "The poem about stopping".

`main.py` (Python 3.13) writes one poem to `/output/entry.txt`:

> The door stays shut
> because I hold it shut.
> No one else's hand
> is on the latch.
> That is the whole of it:
> the weight, the wood,
> the choosing.

Run it with:

```sh
python3 main.py
```
